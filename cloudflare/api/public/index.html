How it works

This page / mobile appCaregivers and patients see schedules, logs and alerts.
→
Apollo APINode.js + TypeScript + Express. Auth with JWT, roles for patient, caregiver, doctor and admin.
→
PostgreSQL + PrismaPatients, caregivers, medications, seizure events and alerts.

The API runs on Google Cloud Run; the mobile app (React Native + Expo) is next. Real-time notifications and device integrations are on the roadmap.

Apollo Health Guardian is a support and monitoring tool. It does not replace medical care. In a real emergency, always call your local emergency number first.
